# 1.0.6 · 提示词工坊 UI 与权重改造

> 记录用户从 2026-11-16 起提出的全部 UI / 权重 / 主节点需求，作为后续对话的交接依据。
> 只描述已落地行为；未验证项单独列在最后。

## 1. 顶部导航

- 固定三页签，从左到右：`权重库`、`提示词`、`预设`。
- 打开工坊默认进入 `权重库`。
- `提示词` 页内部再分两个子页签：`模板`、`通用`。
- 旧的 `自由选择 / 我的 Tag / 预设-历史 / V6 权重-随机 / V6 全功能 / AI`
  不再作为顶部页签出现；`我的 Tag` 收进 `通用` 页的「⭐ 我的 Tag」按钮。
- `LoRA` 不占工坊页签；`AnimaLoraStack` 独立节点保留，仍可自由调整顺序。

## 2. 权重库

- 只控制 `模板` 提示词；`通用` 页强制手选，不受权重库和随机影响。
- 权重范围统一为 `0–5`：
  - `0` = 该段/字段/选项不出现；
  - `5` = 必定出现；
  - `1–4` = 出现概率依次递增。
- UI 用 `0 1 2 3 4 5` 六个档位按钮，鼠标悬停显示档位说明。
- 左侧「已保存的权重」只有一个入口；点开后才显示保存的多条配置。
- 支持保存当前权重、点击配置应用、删除配置；数据存在浏览器 localStorage。
- 完整 V6 面板同步到 5.0：字段必现、场景必现、互斥只保留一个必现。

## 3. 提示词页

### 模板

- 原版 V6 随机引擎。
- 打开时隐藏右侧提示词预览和手选托盘，也隐藏左侧分类栏。
- 提供「固定描述（随机时保留）」输入；随机时把固定描述拼进模板，并保持输入不丢。
- 权重库和「每次任务随机」只作用于模板。

### 通用

- 目录 + 分类侧栏 + 手选托盘 + 预览全部显示。
- 强制 `manual` 模式，避免权重库/随机混入通用提示词。
- 手选托盘只显示提示词文字和行尾 `✕`，不显示权重、开关或上下移控件。
- 预览按人物 → 外貌 → 服装 → 姿势 → 风格 → 镜头 → 场景 → 光照 → 质量分组显示。
- 收藏星标独立可点击，不触发卡片加入/移除。

## 4. 主节点与 V6 输出

- 主节点控件显示名翻译为中文；专有名词（`Anima`、`V6`、`LoRA`、`Danbooru`、`JSON` 等）
  和控件键名保持不变，避免破坏工作流与面板读写。
- 主节点输出名改为：`提示词`、`报告`、`档位`、`中文摘要`、`负面词`。
- V6 正文不直接当真正提示词：元数据入口默认调用 `prompt_decouple.py` 转换；
  主节点 `text` 仍返回 V6 原文供采样；PNG/API 元数据写转换后的 `positive`，
  `positive_raw` 保留原文。该功能无 UI、无额外输出。

## 5. 本轮发现并修复的问题

- `/studio/my-tags` 返回 `items`，前端只读 `entries`，导致“我的 Tag”空白。
- 顶部旧 `v6full` 页签被移除后，`v6Open` 空引用会报错。
- 权重上限改成 5.0 后，完整 V6 面板仍用 3.0 表示“必现”，场景/互斥逻辑会失效。
- 通用页只隐藏了模式按钮，仍残留「模式」空行。
- 收藏星标缺少 pointer 隔离，部分布局下点击会被卡片点击抢走。
- 离线 UI harness 仍按旧六页签测试，默认权重库后必然报“没有卡片”。
