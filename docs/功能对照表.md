## 7. 兼容性

| 项目 | 结论 |
|---|---|
| 是否需要先装 V6 | ❌ 不需要；V6 引擎/数据/面板已内嵌 |
| 是否需要先装 Tools | ❌ 不需要；数据已转换，Danbooru 节点已移植 |
| 能否与 V6 同时安装 | ✅ 可以；节点类名、路由前缀都不同 |
| 能否与 Tools 同时安装 | ✅ 可以；本插件不注册 Tools 类名 |
| 旧 V6 工作流 | 由原 V6 插件继续打开；本插件不抢旧类名 |
| 第三方 Python 依赖 | 无；只用 ComfyUI 自带环境 |
| 运行时联网 | 仅 `AnimaPromptStudioDanbooru` 会联网；其余纯本地 |

## 8. 一句话结论

- **V6 的能力**：随机引擎、档位、三层权重、场景/服装/角色库、体检修复、
  8 页签面板——全部保留。
- **Tools 的能力**：4.2 万画师、8,000 角色、430 服装、297 姿势、1,087 背景、
  6,759 社区 Tag、我的 Tag、多框、多 LoRA、Danbooru——全部并入；5 个专用
  选择器合并为 1 个通用选择器，Civitai 在线下载暂缺。
- **新增的能力**：6.2 万条统一目录、手选托盘、三模式、手选专用报告、
  可拖拽排序的多 LoRA、预设/历史、AI 预留契约。
