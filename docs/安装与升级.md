# 安装与升级

## 1. 环境要求

- ComfyUI：已验证 `0.45.3`；更老的版本只要支持 `PromptServer` 路由和
  `WEB_DIRECTORY`，一般也能用。
- Python：ComfyUI 自带环境即可；已验证 `3.13.12`。
- 第三方依赖：无。不要为这个插件额外 `pip install`。
- 磁盘：插件约 27 MB（主要是 V6 presets + 2,432 张缩略图 + Tools JSON）。

## 2. 安装位置

把整个文件夹放到：

```text
<ComfyUI>/custom_nodes/Comfyui-Anima-Prompt-Studio
```

安装后的第一层必须是：

```text
Comfyui-Anima-Prompt-Studio/
├── __init__.py
├── nodes_studio.py
├── js/
├── presets/
└── ...
```

不能多套一层（例如 `custom_nodes/Comfyui-Anima-Prompt-Studio/Comfyui-Anima-Prompt-Studio/__init__.py`
会导致 ComfyUI 找不到入口）。

## 3. 启动与自检

重启 ComfyUI，控制台应出现类似日志：

```text
[AnimaPromptStudio] v7.0.0 V6 路由已注册: pools / contract / scenes / ...
[AnimaPromptStudio] 新路由已注册: catalog / compose / studio / loras / ai
```

如果只看到 V6 路由、没有“新路由”，说明 `routes_studio.py` 导入失败；看
控制台里的异常栈，通常是 `folder_paths` 或 `server` 导入问题。

浏览器里检查：

```text
http://127.0.0.1:8188/anima-prompt-studio/studio/health
```

正常返回：

```json
{"ok": true, "plugin": "Comfyui-Anima-Prompt-Studio",
 "catalog_total": 62585, "catalog_cats": 31, "ai": false, "loras": 21}
```

`loras` 是本机 `models/loras` 数量；为 0 说明 LoRA 目录没被 ComfyUI 注册，
或还没有放 `.safetensors`。

## 4. 第一次使用

1. 右键画布 → `AnimaPromptStudio` → `Anima 提示词工坊`。
2. 选中节点，点节点上的“🎨 打开提示词工坊”。
3. 左栏选分类，中栏点卡片，右栏托盘出现条目。
4. 调权重/顺序，点“预览出词”。
5. 满意后点“写回节点”；工作流保存时 `studio_json` 会一起保存。
6. 需要 LoRA 时，在 `LoRA` 页签加条目、拖排序，写回节点；把主节点的
   `lora_json` 接到 `AnimaLoraStack`。

## 5. 升级

1. 关闭 ComfyUI。
2. 用新版本整个替换 `custom_nodes/Comfyui-Anima-Prompt-Studio`。
3. 重启。

不会丢的数据在：

```text
<ComfyUI>/user/anima_prompt_studio/
├── studio_favorites.json
├── my_tags.json
├── lora_meta.json
├── lora_stacks.json
└── ai_providers.json
```

会跟着插件版本替换的是 `presets/`（内置词库/缩略图）。如果你改过
`presets/` 里的文件，升级前先备份。

## 6. 卸载

删除 `custom_nodes/Comfyui-Anima-Prompt-Studio`，重启 ComfyUI。用户数据目录
可以保留（下次装回来还在），也可以手动删除。

## 7. 与 V6 / Tools 共存

- 本插件不注册 `AnimaV4RandomPrompt` 等 V6 旧类名，也不注册
  `AnimaArtistSelector` 等 Tools 旧类名。
- 路由前缀是 `/anima-prompt-studio`，V6 是 `/anima-wardrobe-v6` 等；不会抢
  `/health`、`/favorites`、`/thumb`。
- 三个插件可以同时装。打开旧 V6 工作流仍由 V6 插件负责；新工作流用
  `AnimaPromptStudio*` 类名。

## 8. 测试实例（不影响日常使用）

想在不碰日常 ComfyUI 的情况下验证：

```powershell
cd E:\Game\ComfyUI-Installs\Anima模型\ComfyUI
.\.venv\Scripts\python.exe main.py --listen 127.0.0.1 --port 8199 --cpu --disable-auto-launch
```

然后访问 `http://127.0.0.1:8199`。`--cpu` 只是测试用；日常出图请用默认
GPU 启动。测试实例和日常实例共用 `user/comfyui.db` 时会打印“Another
ComfyUI is already using this install's asset database”，不影响启动。

## 9. 常见问题

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 节点列表里没有 `AnimaPromptStudio` | 目录多套了一层 / `__init__.py` 没找到 | 检查第一层文件；看启动日志 |
| 面板按钮点了没反应 | `studio.js` 没加载 / 浏览器缓存 | 看 `/extensions/Comfyui-Anima-Prompt-Studio/studio.js` 是否 200；强刷 |
| 目录一片空白 | `/catalog/meta` 失败 | 看 `studio/health`；检查 `data/tools/*.json` 是否在 |
| 缩略图 404 | `presets/thumbs/` 缺失 | 重新复制 presets；检查文件名 |
| LoRA 列表为空 | `models/loras` 没注册 | 确认 ComfyUI 的 lora 路径；重启 |
| AI 页签按钮灰 | 默认 `enabled:false` | 这是设计；接 provider 后再开 |
| 两个插件同时装，节点重复 | 旧插件没删/类名冲突 | 本插件不复用旧类名；检查是不是旧插件自己的节点 |
